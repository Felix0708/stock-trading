# 사용자별 계좌 주문 실행기

공통 신호 서버는 TradingView 신호를 한 번만 받아 Discord의 `국장-매매신호`, `미국-매매신호`에 **계좌 중립 실행 의도**를 게시합니다. 각 사용자는 자기 컴퓨터에서 계좌 주문 실행기만 실행합니다.

```text
공통 신호 서버
  └─ Discord 매매신호
       ├─ 사용자A 실행기 ─ 키움·한투 모의계좌 ─ 사용자A 전용 기록 채널
       └─ 사용자B 실행기 ─ 키움·한투 모의계좌 ─ 사용자B 전용 기록 채널
```

## 다른 사용자가 준비할 것

1. 이 저장소와 Node.js를 설치하고 `npm ci`를 실행합니다.
2. 키움·한투 중 사용할 증권사의 모의 API를 신청합니다.
3. Discord에서 공용 매매신호 채널은 읽을 수 있고, 자기 전용 주문승인·체결로그·매매일지·포트폴리오·시스템상태 채널에는 쓸 수 있게 합니다.
4. `.env.account.example`을 `.env.account`로 복사해 사용자 이름, Discord ID, 모의계좌 키를 입력합니다.
5. 사용하지 않는 증권사는 `EXECUTOR_KIWOOM_ENABLED=false` 또는 `EXECUTOR_KIS_ENABLED=false`로 끕니다.
6. `npm run self-test` 후 `npm run start:executor`를 실행합니다.

다른 사용자 컴퓨터에서는 `start:signal`과 `start:tunnel`을 실행하지 않습니다. 숨은 백그라운드 서비스도 만들지 않습니다.

## Discord에서 보이는 흐름

- 공용 `매매신호`: 종목·방향·손절·신호 품질과 공통 게이트 결과만 표시합니다.
- 사용자별 `주문승인`: 각 계좌의 현금·보유량·20% 비중 제한으로 계산한 예상 수량을 표시합니다.
- `사줘` 또는 `둘다`: 가능한 키움·한투 계좌 모두 실행합니다.
- `키움만`, `한투만`: 지정한 증권사만 실행합니다.
- `안 사`, `둘다 ㄴㄴ`: 해당 승인 요청을 취소합니다.
- 사용자별 `체결로그`, `매매일지`, `포트폴리오`: 그 사용자의 계좌 결과만 기록합니다.

같은 신호라도 현금·기존 보유·매입 단가·종목 비중이 다르면 수량이나 차단 결과도 달라집니다. 수량을 공통 서버에서 복제하지 않는 이유입니다.

## 상태 확인

사용자별 `시스템상태` 또는 `주문승인` 채널에서 아래처럼 입력합니다.

```text
계좌 명령어 보여줘
계좌 상태 보여줘
사용자A 계좌 상태
계좌 최근 주문 보여줘
```

`ACCOUNT_EXECUTOR_NAME=사용자A`이면 Discord에는 `사용자A 계좌 주문 실행기`로 표시됩니다. 이름 없는 `계좌 상태`는 현재 실행기가 답하고, `사용자A 계좌 상태`처럼 이름을 붙이면 일치하는 실행기만 답합니다. 시작 시에도 사용자 이름, 활성 증권사, 신뢰 채널 수, 실계좌 차단 여부를 한 번 게시합니다. 현재 상태 메시지는 시작·오류·수동 조회를 기록하며 중앙 서버가 각 원격 컴퓨터를 계속 감시하는 heartbeat는 두지 않습니다.

## 토큰과 채널 ID

- `ACCOUNT_DISCORD_TOKEN`: 공용 신호를 읽고 개인 채널에 기록할 Discord 봇 토큰입니다. 신뢰하는 환경에서는 기존 신호 봇 토큰을 재사용할 수 있지만 별도 토큰이 권한 분리에 더 안전합니다.
- `ACCOUNT_SOURCE_CHANNEL_IDS`: 공용 `국장-매매신호`, `미국-매매신호` 채널 ID입니다.
- `ACCOUNT_SOURCE_BOT_IDS`: 위 신호를 게시하는 봇 ID입니다.
- `ACCOUNT_TARGET_GUILD_ID`: 함께 사용하는 Discord 서버 ID입니다.
- `ACCOUNT_*_CHANNEL`: 이 사용자만의 결과 채널 이름 또는 ID입니다.

`.env.account`와 주문 상태 JSON에는 비밀값·계좌 정보가 있으므로 Git에 올리지 않습니다. 공통 신호 서버의 설정은 `.env.signal`, 사용자별 키움·한투 설정은 `.env.account`만 사용합니다.
