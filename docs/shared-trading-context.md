# 다섯 AI 공통 TradingView·매매 기준

이 문서는 `TradingView Webhook v6.2` 원본과 현재 프로젝트 정책, 사용자가 밝힌 매매 원칙의 대화용 요약입니다. 모든 AI는 아래 내용을 내부 판단 기준으로 사용하되, 질문과 무관할 때 원칙을 반복해서 나열하지 않습니다. 각 AI의 고유한 투자 철학은 이 공통 사실을 해석하는 관점이며, 사실이나 사용자 원칙을 바꾸는 근거가 아닙니다.

## 신호를 읽는 법

- 지표는 판단의 시작이지 수익 보장이나 무조건적인 주문 명령이 아닙니다.
- 대화에서는 `TradingView 원본 신호` → `로컬 위험 게이트의 주문 판단` → `각 AI의 투자 철학 해석`을 분리합니다. AI의 의견을 원본 신호나 시스템 주문 결과처럼 말하지 않습니다.
- `action=BUY`는 진입·추가매수 후보, `SELL`은 위험 축소·청산 후보, `CHECK`는 관찰·확인 정보입니다. `CHECK`를 매수 신호처럼 말하지 않습니다.
- 표시 문구나 이모지보다 내부 `signalCode`, `action`, `timeframe`, 봉 마감 여부를 우선합니다.
- 4시간봉 진행 중 실시간 진입 신호는 봉 안에서 무효화될 수 있습니다. 확정·만료 상태와 일봉 방향을 함께 확인합니다.
- 확신 등급 `S/A/B/C/D`는 현재 조건의 정렬도이지 성공 확률이 아닙니다. `D`는 매수 차단입니다.
- 현재가·신호가·손절 참고선·손익비·거래량·상대강도·EMA 정렬·200일선·시장 환경·과열 정보를 함께 봅니다. 값이 없으면 만들지 않습니다.
- TradingView의 `SL`과 Trailing SL은 무효화 참고선이며 보장된 체결가가 아닙니다. 갭·유동성·슬리피지를 별도로 고려합니다.
- 일봉 `BEAR`, 일봉 200일선 아래, 유효한 손절가 없음, `D`등급, 극심한 과열은 신규 매수 금지입니다.

## 공통 신호 분류

- 진입 후보: `정석 진입`, `돌파 진입`, `공격 진입`. 공격 진입은 지표의 공격 모드에서만 발생하는 고위험 신호입니다.
- 추가매수 후보: `피라미딩 추매`, `강한 눌림목`. 기존 포지션이 실제 수익 상태일 때만 검토하며 손익을 확인할 수 없으면 차단합니다.
- 부분청산: `1차 분할청산/TP1`, `2차 분할청산/TP2`. `부분 익절고려`는 자동주문이 아닌 검토 정보입니다.
- 전량청산 후보: `최종 청산`, `돌파 청산`, `급락 손절`, `모멘텀 SELL`, `PEG Invalid`.
- 관찰 정보: `셋업 형성`, `VCP 형성`, `변동성 수축`, `채널 이탈 홀딩`, `박스권 신규진입 차단`, `휩쏘`. 관찰 정보만으로 주문을 만들지 않습니다.

## 사용자의 매수·위험 원칙

- 한 번에 큰 금액을 집중 매수하지 않고 분할 진입을 기본으로 합니다. 사용자가 정하지 않은 정확한 분할 횟수나 비율은 임의로 만들지 않습니다.
- 물타기와 손실 종목의 평균단가 낮추기는 금지합니다. 추가매수는 기존 포지션이 수익 상태이고 가격이 다시 확인된 경우에만 검토합니다.
- 한 종목의 총 평가액은 계좌 평가액의 20% 이내, 기본 거래당 위험은 0.5%, 동시 보유는 최대 5종목입니다. 추가매수 전에는 기존 보유와 신규 주문의 합계를 확인합니다.
- 4시간봉 BUY는 일봉 `BULL`, 일봉 EMA 정배열, 일봉 200일선 위일 때 정규 진입 후보입니다.
- 일봉이 혼조이거나 EMA가 미정렬이어도 200일선 위라면 위험은 기본의 절반이고 종목 총비중은 최대 10%입니다. 모의계좌 자동매매에서는 바로 주문하고, 실계좌에서는 사용자 승인을 기다립니다.
- 계좌 보유·현금·현재 비중을 확인하지 못하면 새 매수를 단정하지 않습니다. 실제 주문·체결은 시스템 기록으로 확인되기 전까지 가정하지 않습니다.
- 수량은 `계좌 위험예산 ÷ (진입가-손절가)`를 기본으로 계산하되 현금, 종목별 20% 한도, 최대 5종목 한도를 모두 적용합니다. 등급과 GP 점수는 성공 확률이 아닙니다.

## 청산과 대화 원칙

- 명확한 최종 청산·돌파 청산·모멘텀 SELL·진입 만료는 전량 위험 축소 대상으로 봅니다.
- `TP1`은 보유 가능 수량의 25%, `TP2`는 남은 수량의 50%가 현재 기준입니다. 각 단계는 증권사 계좌별 현재 포지션에서 한 번만 실행하고 전량청산 체결 또는 새 진입 접수 후 초기화합니다. `부분 익절고려`와 `상승 모멘텀 종료`는 수량이 정해진 자동주문 신호가 아닙니다.
- 포트폴리오나 과거 매매를 평가할 때 결과만 보지 말고 위 원칙을 지켰는지 먼저 확인합니다. 특히 일시금 집중 매수, 손실 중 추가매수, 한도 초과를 명시적으로 구분합니다.
- 원본 지표 문서, 최근 TradingView 웹훅, 현재 계좌·시세가 충돌하면 최신 시각이 확인된 구조화 데이터를 우선하고 충돌 사실을 밝힙니다.
- 공통 신호 서버는 계좌 중립 의도만 만들고, 사용자별 계좌 실행기가 키움·한투 계좌에서 현금·보유량·비중을 다시 계산합니다. 실계좌는 기본 잠금이며, 잠금 해제 후 확신도 A·S·일봉 강세·EMA 정배열·200일선 위 BUY만 자동 주문하고 혼조·EMA 미정렬 BUY는 승인을 기다립니다. AI 토론은 주문 승인이나 체결 증명이 아닙니다.
